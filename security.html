国際航海船舶及び国際港湾施設の保安の確保等に関する法律　過去問準拠問題集

海事代理士筆記試験の公式過去問を踏まえ、国際航海船舶に係る出題範囲を5分野に整理。平成29年～令和7年の出題領域を反復学習できる形に再構成し、令和8年4月1日現在施行法令を基準にしています。

得点源化：この科目は10点の穴埋め型が中心で、近年は同じ制度語が繰り返し問われています。特に「旅客船・500トン・国際海上運送保安指標・船舶警報通報装置・船舶保安統括者・船舶保安記録簿・船舶保安規程・検査」を完全暗記します。
試験範囲注意：令和8年海事代理士筆記試験では、この法律は「国際港湾施設に係る部分を除く」と明記されています。そのため本問題集は船舶関係を中心にし、港湾施設章を主問題から外しています。

1　総則・定義・保安指標

R5・R7で国際航海船舶の定義が反復。『旅客船／500トン／国際海上運送保安指標』は最優先。

2　保安設備・保安措置

船舶警報通報装置等と船舶指標対応措置を区別。設備名と実施措置を一組で覚える。

3　保安管理体制・記録

船舶保安統括者、船舶保安管理者、船舶保安操練、船舶保安記録簿がR5～R7で集中。

4　船舶保安規程・検査・証書

評価→船舶保安規程→承認→検査→船舶保安証書、という一本の流れが最大の得点源。R6は臨時検査まで出題。

5　外国船舶・入港前通報

筆記試験範囲は『国際港湾施設に係る部分を除く』ため、港湾施設章を深追いせず、外国船舶・船舶保安情報の通報を優先する。

直前暗記の一本線

定義 → 保安指標 → 設備 → 指標対応措置 → 統括者・管理者 → 操練 → 記録簿 → 評価 → 船舶保安規程 → 承認 → 検査 → 船舶保安証書。この順番を口で言えるようにすると、穴埋めの位置から答えを推測しやすくなります。

公式過去問の長文をそのまま転載せず、出題された条文・制度・語句を反復学習用の短問として再構成しています。特にR5～R7は公式問題で確認できる出題語を重点化しています。
